# 文本指令引导的图像目标检测系统与演示

**Text-Guided Object Detection for UAV Imagery — Method and Demonstration System**

本项目面向无人机航拍图像，研究**文本指令引导的目标检测**：在检测器给出候选目标的基础上，建立中文指令与候选区域的图文特征匹配，按指令中的**类别、可见颜色、位置与有限相对关系**筛选并定位目标，并输出满足条件的**目标框集合**。在此之上研究**语言模块量化轻量化**，并搭建可交互的**演示系统**。

> 任务定义：输入「无人机图像 + 文本指令」，输出「目标框集合 + 状态」。
> 一条指令可能对应**零个、一个或多个**目标，模型需如实返回空集合或不确定状态，而不是强制给出一个结果。

## 1. 研究内容

| 编号 | 研究内容 | 主要产出 |
| --- | --- | --- |

| C2 | 基于语言模块量化的目标检测模型轻量化 | 浮点/INT8（条件允许时 INT4）配置清单与精度—效率对比 |

## 2. 技术路线

整体采用**检测后图文匹配**主线，而不是端到端重训大型联合模型，以便分离错误来源并控制语言量化的实验变量。

```
无人机图像 ──► YOLOv11s 候选检测（VisDrone 十类微调）
                        │  低阈值候选 → 候选上限 → 紧致/上下文裁剪
                        ▼
                  区域视觉特征 ─┐
                                ├─► 余弦相似度 / 对齐损失 ─► 排序分数 F = f(c, s)
中文指令 ──► Chinese-CLIP 文本编码 ─┘                              │
        └─► 规则/别名表解析（类别·颜色·位置·参照） ──► 几何约束 ────┴─► 目标框集合 / 空 / 待确认
```

关键设计取舍：

- **候选是入口**：目标未进入候选集合，后续语言筛选无法补救；因此除常规 AP 外，额外统计固定候选数量下的召回率、密集区域召回率与定位误差。
- **可学习的外观匹配与可计算的几何关系分离**：语义编码负责类别与可见颜色，左右/上下/中心距离等明确关系由候选框坐标执行，并在实验中比较「纯相似度」与「加入几何约束」的差异。
- **多正样本监督**：一条指令的全部正确目标均作为正样本，避免把其他正确答案当作对比负样本；同类但颜色/位置不符的候选构成困难负样本。
- **拒识与不确定状态**：属性不可辨识、参照对象不唯一或缺失时返回待确认；无候选达标时返回未检出。
- **量化不预设加速**：区分语言模块加速与端到端加速，实测中位数与 P95 时延，并区分权重存储压缩与实际低比特算子加速。

## 3. 数据准备

以 **VisDrone2019-DET** 作为图像与目标框来源（train / val / test-dev 分别为 6471 / 548 / 1610 幅）：

- 保留官方十类：`pedestrian, people, bicycle, car, van, truck, tricycle, awning-tricycle, bus, motor`，建立原始编号 ↔ 训练编号 ↔ 中文名称及别名映射表。
- 原始框（左上角 + 宽高）转换为 YOLO 归一化格式，转换后回画原图核验；类别 0 忽略区域与 `others` 不作为正样本，同时屏蔽其负样本损失。
- 在原始标注上补充**中文指令与目标集合**配对标注，参照 RefDrone 的多目标/无目标设置与复核流程；拟定规模为不少于 1500 / 200 / 300 幅（train/val/test），每幅约 4–6 条指令，无匹配指令比例计划 15%–20%。
- 标注单位是「满足条件的完整目标集合」，并记录可见性、指令类型、参照对象编号与复核结果，使每条指令可追溯到原始图像与目标编号。
- 划分按图像归属继承，同一场景不跨集合；增强不得改变指令含义（水平翻转需同步交换左右条件）。

## 4. 评价方案

- **候选检测**：VisDrone 官方规则报告 AP 与召回。
- **指令定位**：一对一匹配（IoU ≥ 0.5 且目标身份符合指令），报告集合精确率/召回率/F1，按指令类型宏平均 + 总体微平均，另报多目标指令的**集合完全正确率**。
- **空目标指令**：单独报告正确拒识率与误报率，不混入普通均值。
- **轻量化**：相同候选与文本条件下比较精度变化、文本特征方向变化、候选排序一致率，并报告模型大小、峰值显存与分阶段时延。
- **对照设置**：A 仅类别筛选 → B 冻结图文编码器匹配 → C 加入区域级训练 → D 加入几何约束与拒识机制；外部对照为公开权重的 Grounding DINO / YOLO-World（提示语言差异单独说明）。

## 6. 快速开始

> 环境与脚本将随代码实现逐步补充；当前仓库处于骨架阶段。

```bash
git clone https://github.com/<your-account>/text-guided-object-detection.git
cd text-guided-object-detection

conda create -n tgdet python=3.10 -y
conda activate tgdet
pip install -r requirements.txt
```

计划中的命令行入口：

```bash
python scripts/prepare_visdrone.py --root data/VisDrone2019-DET   # 数据转换与校验
python scripts/train_detector.py   --config configs/detector.yaml # 候选检测
python scripts/train_matcher.py    --config configs/matcher.yaml  # 图文匹配
python scripts/quantize_text.py    --config configs/quant.yaml    # 语言模块量化
python scripts/evaluate.py         --config configs/eval.yaml     # 集合指标与效率
python demo/app.py                                                # 启动演示系统
```

## 7. 演示系统

采用**本地推理服务 + 浏览器界面**（Gradio）结构，模型在服务启动时加载，划分为输入管理、指令解析、推理执行、结果展示、记录导出五个模块。

- 结果区同时显示目标数量、边界框、类别、检测置信度、语义匹配分数与总耗时，可展开查看指令解析结果和阶段耗时。
- 无匹配、属性不明确、参照歧义、输入错误**使用不同状态文字**，不统一显示为「检测失败」。
- 支持模型版本切换（权重与分词器、投影层、量化配置一致性校验）、缓存按键失效（指令 + 编码器版本 + 量化配置 + 分词规则）。
- 导出标注图与 JSON（图像编号、原始指令、解析条件、模型版本、量化位宽、候选编号、原图坐标、各类分数与计时），真值标签与推理输入严格隔离。
- 测试覆盖单目标/多目标/无匹配/属性不明/参照缺失/非法文件/超长指令/连续模型切换，计划连续不少于 100 次请求。
