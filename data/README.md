## 类别映射

原始有效类别 1–10 依次映射为训练编号 0–9：

| 训练编号 | 原始编号 | 英文名 | 中文名与别名 |
| --- | --- | --- | --- |
| 0 | 1 | pedestrian | 行人 |
| 1 | 2 | people | 人（people，不直接解释为「人群」） |
| 2 | 3 | bicycle | 自行车 |
| 3 | 4 | car | 汽车 / 轿车 / 小汽车 |
| 4 | 5 | van | 厢式货车 / 面包车 |
| 5 | 6 | truck | 卡车 / 货车 |
| 6 | 7 | tricycle | 三轮车 |
| 7 | 8 | awning-tricycle | 带篷三轮车 |
| 8 | 9 | bus | 公交车 / 巴士 |
| 9 | 10 | motor | 摩托车 |

原始框（左上角 + 宽高）转换为 YOLO 格式：

```
cx = (x + w / 2) / W     cy = (y + h / 2) / H
nw = w / W               nh = h / H
```

转换后检查类别编号、正宽高与坐标范围，并将标签回画原图核验。

## 忽略区域的正确处理

类别 0 的忽略区域与类别 11 的 `others` **不作为十类正样本**；训练时对忽略区域**屏蔽相应负样本损失**，而不是仅删除标签（否则其中的目标会被当成背景）。原始忽略信息与遮挡、截断字段单独保留。最终检测评价使用原始标注与官方工具，不以转换后的十类标签代替完整评价规则。

## 图文配对记录字段

| 字段 | 含义 | 检查要求 |
| --- | --- | --- |
| `image_id` / `split` / `source` | 图像标识、所属集合与来源 | 继承划分，可追溯原图 |
| `instruction` / `type` | 中文指令、类型及生成方式 | 人工核对语义 |
| `target_ids` / `count` | 全部真实目标编号及数量 | 数量与集合一致 |
| `attribute` / `relation` | 属性、位置及参照对象编号 | 属性可见，参照明确 |
| `quality` / `status` / `review` | 可见性、匹配状态及复核记录 | 无匹配与不确定分开 |

## 标注规范要点

- 标注单位是**满足条件的完整目标集合**：如「画面右侧的白色汽车」应关联右侧全部可确认的白色汽车，而不是任取其中一辆。
- 左右/上下以当前图像坐标为准；「最靠近画面中心」按归一化框中心距离排序；边界容差与几何筛选规则保持一致。
- 相对关系优先采用参照明确的表达（如「唯一公交车左侧的行人」），并保存参照目标编号。
- 颜色属性允许「无法判断」，并保留可见性字段；属性不可辨识的区域不作颜色匹配的强制正负样本。
- 无匹配样本可由已核实指令改变一个颜色或位置条件获得，但必须**重新检查整幅图像**确认无任何目标满足；自动生成失败或有歧义的样本记为不确定，不得直接标为空集合。
- 真值**不得**由检测器预测结果生成。

## 划分与增强

- 划分按**采集场景分组**，并检查近重复图像，使同一图像及相近图像的不同表达归入同一集合。
- 检测实验沿用 VisDrone 官方划分；图文配对数据继承其图像的集合归属。
- 增强必须保持指令含义：水平翻转同步交换左右条件；裁剪移除参照物或有效目标时取消该次增强或重写指令；颜色指令不使用会改变颜色标签的强色彩扰动。
- 数据冻结前统计各集合的类别、目标尺度、指令类型及单目标/多目标/无目标分布，并核对跨集合重复情况。
