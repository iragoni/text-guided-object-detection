# 演示系统

文本指令引导的无人机图像目标检测演示系统。采用**本地推理服务 + 浏览器交互界面**（Python 推理服务 + Gradio）结构；模型在服务启动时加载，避免每次请求重新初始化。

演示范围为**静态无人机图像**；视频处理与机载闭环控制不作为本阶段必须实现的功能。

## 模块划分

| 模块 | 职责 |
| --- | --- |
| 输入管理 | 检查图像格式、尺寸与文件完整性；超大图像按上限缩放并提示规则 |
| 指令解析 | 输出类别、属性（可见颜色）与几何条件；未知词、矛盾条件、指代不明返回不支持/待确认 |
| 推理执行 | 候选检测 → 区域编码 → 文本编码 → 匹配与几何筛选 |
| 结果展示 | 原图坐标框绘制；显示目标数量、类别、检测置信度、语义匹配分数与总耗时 |
| 记录导出 | 标注图 + JSON 结构化结果；唯一任务编号，不覆盖先前结果 |

## 状态语义

未发现匹配目标、属性无法判断、参照对象不明确、输入错误**使用不同状态文字**，不统一显示为「检测失败」。属性不清或参照歧义时允许用户修改指令再次查询，不用强制输出目标来掩盖失败。

## 坐标处理

- 图像缩放时保存缩放比例与填充边界，模型输出**先去除填充再映射回原图**，最终坐标裁切到合法范围。
- 切片检测需加回切片偏移后再做全图去重，不能把同一目标在不同切片上的重复输出计为多个正确目标。
- 以包含边缘目标、非正方形图像和大幅缩放的样例检验回映射，不只凭框的视觉位置大致合理判定正确。

## 模型切换与缓存

- 切换时确认权重与分词器、投影层、量化配置一致，**先完成加载再接收新请求**。
- 缓存键 = 规范化指令 + 文本编码器版本 + 量化配置 + 分词规则；模型或量化配置切换后必须失效。
- 缓存命中属于系统优化，语言量化属于数值计算与存储优化，**两者分别测试并报告**。

## 导出字段

```
图像编号 / 原始指令 / 解析条件 / 模型版本 / 量化位宽 /
候选编号 / 原图坐标 / 检测置信度 / 语义匹配分数 / 各阶段耗时
```

真值标签**不写入推理输入**；评测脚本从单独的真值文件读取，保证演示输出与离线评价可复现。

## 测试清单

覆盖单目标、多目标、无匹配、颜色不明确、参照对象缺失、非法文件、超长指令、连续模型切换。每项定义输入、预期状态与输出检查点；计划连续执行不少于 100 次请求，检查未捕获异常、资源持续增长与结果文件缺失，并保存测试日志与修复记录。
