# 配置说明

本目录存放训练、量化、评测与系统运行配置。

计划中的配置文件（随实现逐步补充）：

| 文件 | 用途 | 关键项 |
| --- | --- | --- |
| `detector.yaml` | 候选检测训练 | 骨干/权重来源、输入长边（960 / 1280）、epoch（100–150）、batch、随机种子 |
| `matcher.yaml` | 图文匹配训练 | Chinese-CLIP 权重与分词器、候选上限（100 / 200 / 300）、裁剪扩展（0 / 10% / 20%）、温度 τ、损失权重 λ |
| `quant.yaml` | 语言模块量化 | 位宽配置（W8A16 / W4A16 / W8A8）、分组大小（32 / 64 / 128）、校准集规模（512–1024）、敏感层保留清单 |
| `eval.yaml` | 评测 | 测试集清单、IoU 阈值、融合系数 α、拒识阈值、指令类型子集定义 |
| `demo.yaml` | 演示系统 | 服务端口、模型版本清单、图像尺寸上限、缓存策略 |

约定：

- 所有配置保存 `代码提交号`、`权重来源`、`随机种子`，保证实验可追溯。
- 阈值、量化位宽与层清单**仅在验证集上确定**，测试集只用于冻结方案后的最终评价。
- 不同平台的基准（FP32 / FP16）分开记录，不混合计算加速比。
